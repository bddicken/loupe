Loupe 1.0.8

  • Smoother screen recordings. Recordings now use 60 fps by default, and frames are evenly spaced. Before, about one frame in ten arrived late, which made motion look choppy. If you chose 30 fps in Settings, that’s kept, and it’s smoother too.
  • New default shortcuts. Capture and record shortcuts are now ⌘⇧3 through ⌘⇧8, because the old Option-Shift defaults can stop working on macOS 27.2. Shortcuts you set yourself are kept. ⌘⇧3, ⌘⇧4 and ⌘⇧5 are also macOS screenshot shortcuts, so turn those off in System Settings → Keyboard → Keyboard Shortcuts → Screenshots.
