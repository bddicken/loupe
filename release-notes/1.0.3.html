Loupe 1.0.3

  • Record Loupe itself. Screen recordings now include Loupe's own windows (the editor, Settings, pinned screenshots and thumbnails). Only the recording outline and control bar are left out.
  • Fixed: choosing Save As… on a recording and keeping the same name could delete the recording. Saving over another file now only replaces it once the copy succeeds.
  • If Loupe doesn't have Screen Recording permission, it now says so, instead of saving black recordings or screenshots that show only the wallpaper.
  • Fixed a dark fringe on rounded corners in exported screenshots with a background.
